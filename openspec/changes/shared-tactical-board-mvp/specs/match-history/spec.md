# match-history Spec Delta

## ADDED Requirements

### Requirement: 对局归档与快照

系统 SHALL 在房间归档时将对局快照（对局名称、地图、成员及颜色、全部标注最终状态、起止时间）持久化；快照 MUST 与账号关联，房间每个成员均可查看。

#### Scenario: 归档生成快照
- **WHEN** 房间被归档（手动或自动）
- **THEN** 系统生成对局快照记录，所有成员账号下可查

### Requirement: 历史局列表

系统 SHALL 为已登录用户提供其参与过的历史局列表（按结束时间倒序），展示对局名称、参与成员与结束时间。

#### Scenario: 查看列表
- **WHEN** 用户打开"历史对局"页
- **THEN** 系统展示该用户参与过的全部归档对局，最新在前

### Requirement: 标注快照回看

系统 SHALL 允许用户打开任一历史局，以只读方式回看标注快照：地图上按原颜色渲染全部标注，支持缩放平移，MUST NOT 允许编辑。

#### Scenario: 回看历史局
- **WHEN** 用户从列表中打开某条历史局
- **THEN** 客户端加载快照地图与标注并以只读模式渲染
