# Proposal: shared-tactical-board-mvp

## Why

三角洲行动等撤离射击游戏的三人小队开黑时，靠语音传递敌方位置信息效率低、易失真（"东南坡后面那个石头旁边"）。需要一个共享战术板：队员将敌方情报标注在地图截图上，实时同步给全队，让位置信息一目了然。目前没有轻量、无封号风险的通用工具。

## What Changes

本次变更为全新项目（fighting-plus）的 MVP，从零构建：

- 新增 Electron 桌面客户端（Windows，Vue 3），含主窗口与透明置顶 Overlay 窗口
- 新增 NestJS 服务端（公网部署），提供账号、房间、实时同步、历史局 API
- 新增账号系统：邮箱+密码注册登录（JWT 会话），昵称/头像
- 新增房间系统：房主建房生成邀请码，成员凭码加入，上限 6 人，断线重连
- 新增共享战术板：上传地图图片，多端实时同步标注（点标记+文字、箭头/路线、区域圈选），撤销/重做、橡皮擦、一键清空，标记带时间戳并随时间变淡
- 新增 Overlay 模式：全局热键呼出半透明置顶战术板（纯透明窗口，不注入游戏进程，零封号风险）
- 新增历史局归档与回看（最终标注状态快照）

## Capabilities

### New Capabilities

- `user-auth`: 账号注册、登录、会话管理、昵称与头像
- `room-management`: 房间创建、邀请码加入、成员在线状态、房主移交、归档
- `tactical-board`: 地图上传与画布（缩放/平移）、三类标注、编辑控制、标记时效（时间戳+自动变淡）、实时同步
- `overlay-mode`: 透明置顶窗口、全局热键、点击穿透切换、查看模式
- `match-history`: 对局归档、历史局列表与标注快照回看

### Modified Capabilities

（无——全新项目，无既有规格）

## Impact

- 全新代码库：`client/`（Electron + Vue 3）与 `server/`（NestJS）两个子项目
- 服务端依赖：PostgreSQL（账号/房间/历史持久化）、Socket.IO（实时通道）、对象存储或本地磁盘（地图图片）
- 运维：公网服务器由开发者自行运营，需 HTTPS/WSS
- 范围外：注入式 Overlay、语音/文字聊天、读取游戏内存、内置官方地图
